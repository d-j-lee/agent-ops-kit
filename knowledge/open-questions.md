# 미확인 목록 (open questions)

AOK v1 계획 §8(미확인 목록 → 확인 계획)과 §5(1단계 실현성 시험 T1–T6)에서 옮긴 초기 항목이다.
특정 세션의 기록이 아니라 일반적인 확인 과제다.

**작성 규칙**

- 항목을 확인하면 `상태`를 `확인됨` 또는 `반박됨`으로 바꾸고, 결과를 근거 규약(§2.1)의 등급과 함께 적는다.
- [확인]으로 적으려면 다시 실행하거나 조회할 수 있는 `ref`가 있어야 한다. 실제 `ref`(session id, event uuid)는
  **비공개 원장**의 `verifications`나 비공개 레포에 두고, 이 파일에는 원장 문서 id 같은 일반 포인터만 남긴다(공개 레포).
- 비율은 n≥10부터 쓴다. 그 전에는 원시 건수로 적는다.

| 상태 값 | 뜻 |
|---|---|
| `열림` | 아직 확인하지 않음 |
| `진행` | 시험 중 |
| `확인됨` | 근거와 함께 확인 |
| `반박됨` | 가정이 틀렸음을 확인 |
